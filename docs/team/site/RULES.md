# SITE — NEVER-BREAK RULES (exempt from all size caps: ADD, never delete to fit)
Read EVERY line EVERY session before touching code. One line per rule: the rule, then the failure
that made it law. A rule leaves this file only when the owner himself retires it.

1. NO email landing pages. The confirm link and the human unsubscribe click drop the customer back
   on the site — confirm shows a pill on My checks (`?emconf=1` / `?emconf=0`), unsubscribe opens
   the Alerts sheet so they mute or stop the exact alert (owner 07-16). The POST /unsubscribe stays:
   that is the machine-to-machine one-click path mail apps call, and it is not a page.
2. Staging is a PRIVATE REPLICA, never password-walled. A Basic-auth / login-form gate was constant
   friction on iOS and bought nothing; the replica is private by obscurity of its address instead.
3. The FAQ lives in the book (readme.com). /p/faq redirects there — never re-create an on-site FAQ.
4. Link-preview bots must reach the share landing even while the coming-soon splash is up, or shared
   finds unfurl as the splash. `/s` is exempt from the splash gate for exactly this reason (07-14).
5. Clerk is fully removed. Sessions are phone/SMS only; there are no email-domain admin checks, so
   staff/test accounts are flagged by hand.
6. The logo wall is the RECORD OF TRUTH for artwork: it shows exactly what a customer sees, so it
   can never show a copy the site does not serve (owner 07-31). Change a logo in one place only.
