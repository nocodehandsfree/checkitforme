# ADMIN — NEVER-BREAK RULES (exempt from all size caps: ADD, never delete to fit)
Read EVERY line EVERY session before touching code. One line per rule: the rule, then the failure
that made it law. A rule leaves this file only when the owner himself retires it.

1. Admin ships on its own path, not on a promote: the screens are uploaded to the service volume and
   go live in seconds. The last 5 versions are kept so a bad one can be rolled back immediately.
2. Cost and margin figures count ONLY checks carrying a stamped receipt from the owner's clean slate
   (07-26). Rows older than that are false and must never be averaged into a rate.
3. The person at a store is Staff — in every Admin label, every export, every screen. Never "clerk",
   never "agent", never "rep".
4. Owner-only stores (the Fun rehearsal store) are excluded from every Admin report and metric that
   aggregates check results, exactly as they are hidden from the public store lists.
